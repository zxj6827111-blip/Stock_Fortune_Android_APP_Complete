# 使用说明 · 股运通 v1.2.0

> 本应用为传统八字命理模型与 A 股上市时间数据的**研究性推演工具**，完全离线运行，
> 不提供任何涨跌预测、收益回测或投资建议。

## 0. 数据口径速览

- 股票的"八字"= **上市首日的四柱**，时辰固定取开盘时刻 **09:30（巳时）**，时干由日干按五鼠遁推出。
- 财星判定按 **Rule v1.1 透干优先**，逐柱独立判定（细节见 §2）。
- 日主强弱按 **Rule v1.2**：年月日**六字**加权，**刻意不含时柱**（全市场时支恒为巳，是同一常数项，详见「我的 → 算法口径」二·五）。三态为 身强 / 中和 / 身弱，权重与阈值是本项目工程取值，**无古籍依据**，界面一律标「本项目概述」。
- 日柱按 60 甲子连续推进；年柱以**立春**为界、月柱以**十二节**为界，交节当日即换柱。
- 详情页"阴阳类型"取自数据源的**首日涨跌标识**（收盘高于/等于开盘为阳，低于为阴），不是日干的阴阳；十神计算另用日干阴阳。
- 收录 5395 只 A 股（沪 2278 / 深 2853 / 北 264），数据快照 2025-02-06。
- 行业为三级分类（如 `食品饮料-饮料-白酒`）：列表与详情页的"所属行业"显示一级，"细分行业"显示二三级（相邻同名自动合并）。

## 1. 首页

- 顶部搜索框输入 **股票代码或名称**（支持 `600519`、`600519.SH`、`茅台`），回车或点右侧按钮进入结果页。
- 四个快捷入口：股票查询 / 每日扫描 / 交易日历 / 八字择日。
- **今日概览**显示最近交易日的正财股与偏财股数量，点数字卡直接进入对应筛选结果。

## 2. 股票详情（4 个 Tab）

| Tab | 看什么 |
|---|---|
| 基本信息 | 代码、名称、上市日期、板别、属性；四柱八字与每柱五行；阴阳属性、纳音、**日主强弱**、命理特征（强弱与命理特征均标「本项目概述」） |
| 年度运势 | 流年干支与五行、整体财运、行业影响、总体建议；12 个干支月各一行：**月干支 + 交节日期区间 + 月干十神 + 财星 + 该月判词** |
| 月度运势 | 月干支、月令五行旺衰、与日主关系、月运简述；**交易日十神分布日历**（红点正财、橙点偏财、灰点其他，非交易日置灰） |
| 每日分析 | 仅列交易日：日期 / 星期 / 干支 / 流日天干十神标签 |

- 右上角星标可收藏，收藏项在"我的"页查看。
- 年度页点某个月 → 跳到该月月度页；**月度页与每日分析页点某一日 → 单日详情**。
- 年度页的逐月行按**干支月**排，行内的日期区间是该干支月的首末两个自然日（交节当日即换月，如丙午年庚寅月 = 2.4–3.4），**不是公历月首末**；月柱在一个干支月内恒定，所以行内判词取月内任一日都是同一句。
- 图例里的**「其他」与「无」不是一回事**：「其他」= 该月干支皆不为财星但确有十神当值；「无」只用于非交易日。年度页不会出现「无」。
- 每行的判词由「月干十神 × 日主强弱」拼出（30 格），与月度页「月运简述」是同一函数产出，同一个月在两页文字一致。

### 单日详情页（某只股票 × 某一天）

四张卡片，从上到下就是"看一天"的完整链路：

| 卡片 | 内容 |
|---|---|
| 当日信息 | 股票名称/代码、日期与星期、流日干支与五行、**该股日主**（十神全部以它为参照）、是否交易日、该日节气 |
| 四维十神 | 流年 / 流月 / 流日三行，每行三列：**干**（天干十神）、**支**（地支本气十神）、**财**（该柱财星，无财则不显示）；第四行"藏干"是本命四柱藏干去重后的十神集合 |
| 本命藏干明细 | 四柱地支的每一个藏干逐行列出（柱 / 藏干 / 十神 / 气位），按 本气 → 中气 → 余气 排序。明细行数通常多于"藏干"标签数，因为同一十神在多个地支重复出现只归一次 |
| 流日财星判定 | 判定结论 + **推导链**：日主五行与财星五行 → 该日天干与地支本气的十神 → 透干或本气命中（或"均不见财星，判定为其他"）→ 若地支中气/余气藏财，会注明"藏而不透，按口径不计入判定" |

- 判定口径是 **Rule v1.1**：只看该柱天干与地支**本气**，中气/余气藏干不参与（否则全市场命中率会虚高到 39%）。
- 非交易日进入该页，财星判定卡只显示"非交易日"，不给结论。

## 3. 每日扫描（底部"扫描"）

- 顶部日期 chip 左右箭头切换日期；两张统计卡是当日正财/偏财股票数。
- `全部 / 正财 / 偏财` 三个 Tab 切换列表；表格列为 序号 / 代码 / 名称 / 行业 / 十神类型。
- 标签带 `·藏` 后缀表示该财星不是天干透出、而是日支本气所藏（隐性财）。
- 点任意行进股票详情。

## 4. 十神筛选（底部"选股"）

四个维度，**组内多选为"或"，组间为"且"**：

1. 藏干十神 —— 股票自身八字四柱地支藏干中含所选十神
2. 流年十神 / 流月十神 / 流日十神 —— 相对"当日"的流年、流月、流日干支十神

**基准日期**：卡片顶部可选择日期（‹ › 逐日切换、点日期打开月历选择器、"最近交易日"一键回跳）。
因为"流年/流月/流日十神"都是相对某一天成立的，换日期就等于换一套时间坐标 ——
三个分组的标题会实时显示当前基准日的干支，例如"流日十神 · 丙午"。

勾选状态会被记住，下次进入自动回填。点"开始筛选"出结果。
结果行显示的是**该股命中的十神标签**（不是当日财星），命中维度多的排在前面；
超过 50 条只展开前 50 条并提示继续收紧条件。

## 5. 八字择日

输入股票代码 + 起止日期（默认本月），点"开始分析"，返回区间内命中正财/偏财的日期列表，
并标注每个日期是否为交易日；可勾选"仅看交易日"。区间上限一年。

## 6. 交易日历（底部"日历"）

按月查看交易日分布：绿点 = 交易日，灰点 = 休市（周末或节假日）。
点某天看当日干支、休市原因与数据可信度（已公布安排 / 规则推算 / 实测反查）。

## 8. 常见问题

**Q：为什么效果图里的干支和 APP 里不一样？**
效果图中的具体干支/十神是设计示意值（例如 600519 图上写"戊辰/壬子"，数据源实为"壬戌/乙巳"）。
布局、层级、配色以效果图为准，**数值一律以数据源与算法为准**。

**Q：为什么某天的偏财股是 0？**
v1.1 之前采用"命中集合含正财即判正财"，会在丙午这类"透偏财、藏正财"的日子把偏财吞掉。
现已改为**透干优先**，正财与偏财各自独立成列表。

**Q：单日详情里财星判定为什么是"其他"？**
"其他"不是缺数据，而是该日**天干与地支本气都不见财星**。例：000605 渤海股份日主癸水，水克火为财，
财星只有丙（正财）、丁（偏财）；2026-09-01 为戊寅日，戊是正官、寅本气甲是伤官，故判"其他"。
寅中虽藏丙火（正财），但属中气、藏而不透，按 Rule v1.1 不计入。页面底部的推导链会把这四步逐行写出来。
同一只票在 2026-09-09（丙戌日）就判"正财"，因为丙直接透在干上。

**Q：日主强弱是怎么来的？为什么会有"中和"？**
按年月日六字加权（得令/得地/得势三分结构），同党（比劫、印）取正、异党（食伤、财、官杀）取负，
总分 ≥ +2.0 记身强、≤ −2.0 记身弱、其间记中和。**时柱不计**：本应用时支对全部 5395 只恒为巳，
那一项对每个盘都是同一个常数，留着只会放大日主之间的偏差。三分结构是子平通说，但**权重与阈值是本项目的工程取值，
没有任何古籍依据**，所以页面上标「本项目概述」而不挂书名；「中和」是为了不把边界盘硬判成强弱。
现库分布：身强 888 / 中和 1834 / 身弱 2673。

**Q：为什么同一个十神，两只股票的判词不一样？**
判词由「十神 × 日主强弱」两轴决定（10 × 3 = 30 格）。同一个十神在身强身弱下读法相反 ——
比肩于身弱是帮身、于身强是分财；印于身弱是护身、于身旺是因循。这是 Rule v1.2 加这根轴的原因。
若某月财只藏在地支本气而未透干，行首会写「正财藏支」而不是「透正财」。

**Q：能联网更新数据吗？**
不能，也不可以。本应用不声明网络权限，更新数据需用电脑重跑 `tools/build_all.sh` 重新打包（见 `release/README.md`）。

**Q：2027 年之后的交易日准吗？**
2017-2026 用已公布的放假安排；2027 及以后为规则推算，日历页会标注"规则推算"。周末一律休市这点是确定的。

**Q：行业数据从哪来？**
来自 `input_data/行业分类.xlsx`（股票代码 / 股票名称 / 所属行业三级），与主表 5395 个代码一一对应、无缺口。
更新时替换该文件并重跑 `bash tools/build_all.sh`。
