# ADR-0007: 合规禁词门禁零容忍与「忌神」渲染标签映射策略

## 状态
**ACCEPTED**（2026-10-09）

## 背景
股运通作为合规优先的传统文化离线工具，设立了极为严密的 60 个禁词门禁（包括收益暗示类如「收益」「翻倍」「暴涨」，以及操作指令类如「加仓」「止损」「忌」「避免」等）。
在引入喜用神体系时面临关键冲突：
- 传统命理规范术语包含「用神、喜神、忌神、仇神、闲神」。
- 词库中的单字「忌」是核心禁词，用于防止出现「忌合伙投资」等诱导性建议。
- 若直接输出「忌神」，将直接破坏现有合规门禁；若为放行外部文案而从禁词表中删除「忌」，将违背合规底线原则（「禁止删除、缩窄原有禁词测试」）。

## 决策
1. **测试门禁零削减**：保留现有 60 个合规禁词测试，严禁删除单字「忌」，严禁收窄测试范围。
2. **数据层与展示层解耦**：
   - **底层数据模型**（Kotlin / Room / SQLite / JSON）：保留命理学通用枚举与字段名 `ji_shen`，保证学术命名规范。
   - **UI 渲染与文案呈现层**：通过统一的 `LabelMapper` 实施中性化雅称映射：
     - `忌神` $\rightarrow$ `制衡之神` 或 `相逆之神`
     - `仇神` $\rightarrow$ `耗身之神`
     - `闲神` $\rightarrow$ `助势之神`
3. **补充资产数据库全表扫描门禁**：在既有 `ComplianceTextTest` 基础上，新增针对 SQLite 预置库所有文案表（如 `advice_fragment`, `luck_cycle_text` 等）的行级全量 60 词扫描测试，确保无任何合规盲区。

## 后果
- 兼顾了命理底层学术命名的严谨性与对外展示的绝对合规性。
- 100% 杜绝因引入外部文案或喜忌术语而导致的合规风险。
