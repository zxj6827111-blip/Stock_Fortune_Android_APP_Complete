# ADR-0002: 平盘、缺失与冲突样本显式标记与大运不适用处置

## 状态
**ACCEPTED**（2026-10-09）

## 背景
全量 5395 只股票中：
1. 有 315 只股票上市首日涨跌幅 `first_change == 0.0`（首日平盘）。历史原始数据源将这些平盘股票全数静默标记为「阳」，占阳性样本的 8.7%。
2. 有 1 只股票（`000004.SZ 国华网安`）上市首日涨跌幅为「数据缺失」。
3. 历史系统中缺乏对平盘与缺失的显式状态表达，易在排盘推演中引入虚假先验偏置。

## 决策
1. 扩展首日命别极性枚举为五态：
   - `YANG`（阳，`first_change > 0`）
   - `YIN`（阴，`first_change < 0`）
   - `FLAT`（平，`first_change == 0`，315 只）
   - `MISSING`（缺失，行情缺失，1 只）
   - `CONFLICT`（冲突，多源数据校验不一致）
2. 平盘并非上涨，不能归阳；缺失不可猜测。对于 `FLAT`、`MISSING`、`CONFLICT` 状态的股票：
   - 裁定其大运方向为 `UNAVAILABLE`（不适用）。
   - 数据库中不生成伪造的大运周期干支序列。
   - 详细记录原因码（`FIRST_DAY_FLAT_UNRESOLVED`、`FIRST_DAY_FLAG_MISSING`）。
3. Android UI 层向用户清晰呈现「首日平盘/数据缺失，命别阴阳未定，大运不适用」，做到诚实展示边界。

## 后果
- 杜绝 315 只平盘股票被误标为阳而引入的数据源噪声。
- 确立系统的 Fail-Closed 原则：宁缺毋滥，不可判定的命理结构绝不捏造数据。
