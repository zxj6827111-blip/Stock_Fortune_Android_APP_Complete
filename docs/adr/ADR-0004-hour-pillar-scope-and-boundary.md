# ADR-0004: 时柱参与范围与命理推导隔离边界

## 状态
**ACCEPTED**（2026-10-09）

## 背景
股票「八字」与自然人出生命理八字存在根本区别：自然人出生时刻分布于十二个时辰；而 A 股统一于北京时间 09:30 开盘，所有股票上市时支均为巳时。
历史库中记录了 `hour_pillar`，并在 `stock_hidden_ten_god` 中包含了时柱藏干十神记录。这导致在不同计算模块中存在「时柱是否参与」的口径模糊：
- 强弱计算剔除了时柱（六字）；
- 藏干十神展示包含了时柱；
- 原局内部刑冲合害与喜用候选若盲目引入时柱，会导致所有股票无一例外受到巳火的刑冲克合作用（如所有申金皆被巳申合化，所有亥水皆被巳亥相冲），严重扭曲原局关系分布。

## 决策
1. **严格隔离时柱参与范围**：
   - **纳入范围**：`stock_bazi.hour_pillar` 数据库存储、四柱详情卡片展示、本命藏干十神历史条件筛选（保持 V1.2 既有行为兼容）。
   - **绝对排除范围**：日主强弱计算、原局内部关系识别（3×3）、流年流月岁运互动判定、喜用神候选计算。
2. **界面明确告知**：
   - 股票详情页四柱卡片和命理依据推导链中，显著标注：「时柱统一按开盘巳时记录，按系统口径不参与强弱、格局及刑冲合害推导」。

## 后果
- 原局内部关系（3×3 矩阵）与强弱基础完全同源、自洽。
- 彻底消除了将统一开盘时间作为人为全局刑冲因子的系统性偏差。
