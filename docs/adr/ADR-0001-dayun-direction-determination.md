# ADR-0001: 大运顺逆方向由年干阴阳与有效首日阴阳联合裁定

## 状态
**ACCEPTED**（2026-10-09）

## 背景
传统八字命理中，大运的顺行或逆行由「年干阴阳」与「性别（乾造阳/坤造阴）」共同决定：
- 阳男阴女顺行，阴男阳女逆行。

在股票拟人化八字体系中，股票没有生物学生理性别，V1.2 约定将股票上市首日涨跌符号（收盘价相对开盘价之涨跌）映射为股票命别（阳=收涨，阴=收跌）。
然而，兄弟参考平台在 `stock_fortune.py:252-256` 编排层中，错误地将 `compatibility_variant_mode` 直接绑定首日阴阳，导致其在阴年样本（如乙、丁、己、辛、癸年上市的股票，占全库 50.1%）中，计算引擎反解出的实排干支序列与元数据中的 `direction` 字段完全相反（实排顺行但字段记为逆行，或实排逆行但字段记为顺行）。

## 决策
1. 废除依赖兄弟平台排运器编排层的做法，在 Android V1.3 构建期构建器中统一执行自洽的大运顺逆裁定：
   $$\text{Direction} = (\text{YearStemPolarity} == \text{ProxyGenderPolarity}) \ ? \ \text{FORWARD} : \text{REVERSE}$$
2. 四象限定义：
   - 阳年 + 阳命 $\rightarrow$ FORWARD（顺行，月柱干支序号 $+1$ 递增）
   - 阳年 + 阴命 $\rightarrow$ REVERSE（逆行，月柱干支序号 $-1$ 递减）
   - 阴年 + 阳命 $\rightarrow$ REVERSE（逆行，月柱干支序号 $-1$ 递减）
   - 阴年 + 阴命 $\rightarrow$ FORWARD（顺行，月柱干支序号 $+1$ 递增）
3. 增加单元测试与回归夹具，强制断言：每一个生成的周期干支步进序列与 `stock_luck_cycle.direction` 字段必须 100% 严格一致，出现矛盾立即熔断构建。

## 后果
- 纠正了阴年 2699 只股票排运反向的重大历史活缺陷。
- 保证构建入库的干支序列在任何年份下均符合传统命理规范与严密自洽性。
