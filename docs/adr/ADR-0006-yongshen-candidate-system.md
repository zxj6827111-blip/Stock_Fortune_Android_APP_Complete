# ADR-0006: 基于三柱六字强弱的同源喜用候选计算系统

## 状态
**ACCEPTED**（2026-10-09）

## 背景
传统八字中的喜用神推导极其复杂，通常包含扶抑、调候、通关、病药、从格与专旺等多种派系与规则。
研究平台的喜用神实现存在若干明显局限：
1. 仅实现了扶抑三分支与调候改写，无候选列表；
2. 缺乏从格、专旺、通关等完整命局处理；
3. 其 availability 在代码中被写死为 `OK`，无法表达「中和格局喜用不显著」或「未定格局」；
4. 平台自身对喜用神阈值与输出没有任何有效单元测试断言。

## 决策
1. 研究平台的喜用神实现仅作为**参考实现**，严禁将其直接作为权威 Golden 准则。
2. Android V1.3 喜用神推导必须与三柱六字强弱轴**同源计算**，不引入外部四柱结果覆盖本地强弱。
3. 建立 `YongshenCandidateResult` 结构，包含明确的状态枚举：
   - `CONFIRMED`（已确定）：身强身弱分明，扶抑主轴明确。
   - `CANDIDATE`（候选集）：中和命局或同党异党平衡，输出五行建议候选列表，不强制唯一判定。
   - `UNAVAILABLE`（不适用）：特殊命局或边界超出当前离线模型支持范围时，显式保持不可用。
4. 扶抑逻辑与调候提示分离表达，调候作为环境辅助参考，不直接暴力覆盖扶抑五行。
5. 严禁使用虚假硬编码置信度（如 0.85）充当统计概率。

## 后果
- 避免了强行给所有股票强加唯一喜用神导致的学术与工程破绽。
- 确保命理推导透明、严谨、可追溯，不伪造命理结论。
